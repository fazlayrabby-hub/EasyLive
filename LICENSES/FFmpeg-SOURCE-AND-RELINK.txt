FFmpeg in EasyLive: source code, build, and your right to replace it
===================================================================

What EasyLive ships
-------------------
EasyLive loads the FFmpeg libraries (as DLLs, in the "ffmpeg" folder next to EasyLive.exe):

    avcodec-62.dll  avformat-62.dll  avutil-60.dll  swscale-9.dll  swresample-6.dll

They come from the prebuilt "LGPL shared" Windows x64 build of FFmpeg 8.1 published by the BtbN
FFmpeg-Builds project (file name pattern: ffmpeg-n8.1-latest-win64-lgpl-shared-8.1.zip). The build
used for this package reports "ffmpeg version n8.1.3-39-g660b5aa7db-20261122" and was configured with
--enable-version3 and WITHOUT --enable-gpl, WITHOUT --enable-nonfree, with --disable-libx264 and
--disable-libx265. It is therefore licensed under the GNU Lesser General Public License, version 3
(see FFmpeg-LGPL-3.0.txt). EasyLive does not ship ffmpeg.exe, ffprobe.exe or ffplay.exe.

Where to get the source code
----------------------------
* FFmpeg source:           https://github.com/FFmpeg/FFmpeg   (release branch release/8.1, commit g660b5aa7db;
                           or any n8.1.x tag; source tarballs: https://ffmpeg.org/download.html)
* Build scripts used by BtbN (they also fetch and build every third-party library that is linked in):
                           https://github.com/BtbN/FFmpeg-Builds
* Prebuilt binaries:       https://github.com/BtbN/FFmpeg-Builds/releases
* The libraries linked into this build (dav1d, libaom, OpenH264, opus, libvorbis, libvpx, ... ) are listed
  in the "configuration:" line printed by "ffmpeg -version"; their source is fetched by the BtbN scripts.

If you received EasyLive from someone and cannot reach those sites, the person who gave it to you is asked
to provide the corresponding FFmpeg source for the same version on request, for at least three years after
the version was distributed.

Your right to replace the FFmpeg libraries (LGPL "relinking")
-------------------------------------------------------------
The FFmpeg libraries are separate, dynamically loaded DLL files. EasyLive.exe and EasyLive.Core.dll are NOT
statically linked with them. You may replace them with your own modified or self-built version of
FFmpeg 8.1 (same DLL names and major versions: avcodec-62, avformat-62, avutil-60, swscale-9,
swresample-6) by:

  1. copying your DLLs into the "ffmpeg" folder next to EasyLive.exe (overwriting the shipped ones), or
  2. putting them in any folder and setting the environment variable EASYLIVE_FFMPEG_DIR to that folder
     (EasyLive looks in "<app folder>\ffmpeg" first, then in EASYLIVE_FFMPEG_DIR).

How to rebuild FFmpeg like this one
-----------------------------------
    git clone https://github.com/BtbN/FFmpeg-Builds
    cd FFmpeg-Builds
    ./makeimage.sh win64 lgpl 8.1      # needs Docker
    ./build.sh win64 lgpl 8.1 shared   # produces ffmpeg-n8.1-...-win64-lgpl-shared-8.1.zip in artifacts/
(See the README of that repository for current instructions; the exact commands may change.)
